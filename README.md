# PeerPulse
PeerPulse is a web-based mentorship platform that addresses the knowledge gap and academic isolation faced by juniors university students when navigating the new and difficult courses. By providing a matching between mentor and mentee based on course history and scheduled availability, the system will help students to achieve academic confidence through peer support. The software will be built using Agile principles, iteratively refining the solution based on the users feedback. 

## Project Vision
Our project seeks to develop a web-based mentorship platform that addresses the knowledge gap and academic isolation faced by juniors university students when navigating the new and difficult courses. By providing a matching between mentor and mentee based on course history and scheduled availability, the system will help students to achieve academic confidence through peer support. The software will be built using Agile principles, iteratively refining the solution based on the users feedback.

## Problem Statement
Junior students often struggle to adapt to the increased difficulty or find reliable guidance for specific university courses. They struggle to navigate major specific requirements and have issues in gaining practical and relatable advice on the technical skills to handle university. Existing campus communication is not as effective between junior and senior students which makes it harder for juniors to learn from the senior students who have successfully cleared similar paths, thus wasting a useful resource.

## Target Users
| Role | Who they are | What they need |
| --- | --- | --- |
| **Mentees** (junior students) | Students seeking academic guidance | Course insights, skill-building help, and targeted support from experienced peers |
| **Mentors** (senior students) | Students who have completed relevant courses | A way to share knowledge, set availability, build leadership skills, and give back |
| **Administrators** | Platform operators | Mentor verification, course-record integrity, and a safe community |

## User Stories
**As a junior student**,  I want to be able to search for senior mentors who have completed specific courses so I can receive targeted academic guidance. I want to be able to schedule meetings and be able to view feedback from my mentors for my growth.
**As a senior student**, I want to be able to sign up as a mentor, set my availability and list my skills so that juniors can easily book relevant help sessions with me.
**As an administrator**, I want to verify accounts and have course records so that the academic integrity and platform safety are preserved.

## Project Goals
1. Create an easy to use interface for students to register, build profiles and collaborate and guide each other to complete coursework and share meaningful information and guidance.
2. Implement some form of matching/filtering that allows for juniors to pair up with qualified seniors based on the shared courses and overlapping availability.
3. Implement a scalable object oriented solution that can grow with the number of users and manage session bookings.

## High-Level Features
### 1. Profile and class repository
- This category will include the user's account management. For mentees and mentors this will contain their information on name, year of university, completed courses, certifications and technical skills. 
- This ensures that mentors can accurately advertise their expertise and mentees can search for their exact course specific support 

### 2. Smart matching and search engine
- This category covers the matching process as well as multi criteria filtering and schedule overlap searches 
- This fulfilled the projects goal of connecting users efficiently based on their specific needs and availability without manual friction 

### 3. Mentorship sessions and feedback
- This category focuses on session scheduling tools, connection and feedback tracking to maintain community and quality improvement 
- This provides structure to the mentoring relationship and ensures active collaboration and tracking to ensure quality is maintained and improved.
